> Enterprise React Native app for Nivoda's global B2B diamond marketplace. Jewellers and buyers search, filter, view, and purchase diamonds, manage orders, track shipments, and pay — on Android & iOS.

- Built diamond search & filtering with product detail views and complete order management flows
- Integrated **Stripe** payment gateway for seamless in-app purchases and multi-tier subscriptions
- Reduced API integration time by **~40%** using **GraphQL Codegen** for auto-generated typed hooks
- Integrated **Claude AI (Anthropic SDK)** for code generation and development workflow automation

- Set up E2E test suite with **Appium** covering critical user flows
- Integrated real-time push notifications for order and booking status updates
- **Stack:** React Native 0.76, Expo SDK 52, TypeScript, Apollo Client, GraphQL Codegen, Zustand, Claude AI
